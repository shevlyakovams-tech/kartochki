# Карточки EN · DE

Тренажёр слов по английскому и немецкому для школьника (8 класс): карточки с интервальным повторением, тест уровня, озвучка, свои фото к словам, загрузка своих списков слов.

Открыть на телефоне и выбрать «Добавить на главный экран» — после первого запуска работает без интернета. Прогресс хранится на устройстве.
